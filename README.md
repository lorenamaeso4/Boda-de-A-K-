# A // K — demo de boda

Demo estática bilingüe (español/ruso) para propuesta visual.

## Abrir

Abre `index.html` en un navegador. No necesita dependencias ni servidor.

## Personalizar

- Cambia la fotografía de portada en `assets/hero-cover.png` (o actualiza `.hero-photo` en `styles.css`).
- Las imágenes de hormigón están en `assets/` y se pueden sustituir conservando esos nombres o actualizando las rutas CSS.
- Los datos sin confirmar aparecen como «Por confirmar» / «Уточняется».
- El formulario RSVP y la playlist son demostrativos: no envían ni persisten información.

La portada usa la imagen compartida para esta versión de la demo. El apartado «Nuestra historia» contiene un texto genérico de muestra para personalizar con la historia real de la pareja.
